# GPTV updates

Public distribution channel for the GPTV Android TV and Android tablet apps. This repository holds release assets only (APKs, update manifests, checksums); no source, configuration or media.

- Android TV: https://github.com/Palmbeachtotalcontrol/gptv-updates/releases/latest/download/gptv-tv.apk
- Android tablet: https://github.com/Palmbeachtotalcontrol/gptv-updates/releases/latest/download/gptv-tablet.apk

Installed apps check `gptv-tv-update.json` / `gptv-tablet-update.json` from the latest release and verify the APK's SHA-256, package and signing certificate before installing.
